# Pankaj Kumar – Creative Developer Portfolio

A personal portfolio website built with HTML, CSS, and JavaScript. It introduces **Pankaj Kumar** as a Creative Developer and presents skills and selected projects through a modern, animated interface.

## Pages

- **`landing.html`** – Introductory landing page with the name, role, and a *Get Started* link.
- **`Home.html`** – Main portfolio page containing the skills section, selected projects, and social profile links.

## Features

- Dark-themed, modern visual design
- Responsive layouts for desktop and mobile screens
- Animated page entrance and text reveals
- Smooth scrolling and scroll-progress indicator
- Interactive hover effects on project cards
- Animated skill ticker
- Skills grouped into categories
- Selected project cards
- GitHub and LinkedIn links
- Reduced-motion support for accessibility
- Google Fonts: Space Grotesk and Inter

## Technologies Used

- HTML5
- CSS3 (custom properties, Grid, Flexbox, animations, media queries)
- JavaScript (DOM manipulation, event listeners, `IntersectionObserver`, `requestAnimationFrame`)
- Google Fonts

## Skills Showcased

- **Frontend:** HTML5, CSS3, JavaScript, React, Bootstrap
- **Programming & Data:** Python, C, MySQL, Miniconda
- **Hardware:** Arduino
- **Design:** Figma, Canva

## Projects Displayed

- **Python Games** – Arcade-style games coded in Python
- **CareerMatch-By-PK** – Helps students match with a suitable career path
- **DevTrack** – Tracks developer work and progress
- **Qvanta** – A project built around the Qvanta idea

## Run Locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Keep `landing.html` and `Home.html` in the same folder.
3. Open `landing.html` in a browser.
4. Click **Get Started** to open the main portfolio page.

> If you place the files in different folders, update the links in the HTML accordingly.

## Customization

- Update the skills array and project data in the JavaScript section of `Home.html`.
- Edit the text and links in the HTML to personalize the portfolio.
- Change colors and layout through the CSS variables near the top of each file.
- Replace the GitHub and LinkedIn URLs in the footer with the correct profile links.
